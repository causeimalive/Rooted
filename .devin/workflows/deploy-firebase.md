1. Confirm the app lives in `web/` and that Firebase Hosting is configured in `web/firebase.json`.
2. Build the app from `web/` with `npm run build`.
3. Deploy the built output to Firebase Hosting using the `portal` target and Firebase project ID `rootedinchrist-faith-2026`.
4. After deployment, verify the site is serving from `https://rootedinchrist.faith/` and note any Firebase CLI output or configuration issues.
